# Commissioni Bonifici LipariBank

## Bonifico SEPA standard

Le commissioni per bonifico SEPA verso conti correnti di altre banche all'interno dell'area SEPA sono:
- Online (app o web): €1.00
- Allo sportello: €5.00

Tempo di esecuzione: 1 giorno lavorativo per bonifici disposti entro le ore 14:00, 2 giorni per quelli oltre.

## Bonifico istantaneo SEPA

Disponibile per importi fino a €15.000:
- Costo: €1.00
- Tempo: <30 secondi

## Bonifico estero (extra-SEPA)

Bonifici verso paesi fuori area SEPA:
- Costo: €15.00 + 0.20% dell'importo.
- Tempo: 3-5 giorni lavorativi.
